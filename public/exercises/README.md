# Exercise images

One image per exercise, named `<exercise-id>.webp` (the id is in `src/data/exercises.ts`).
ChatGPT saves PNGs (about 1.6 MB each); convert them to WebP at quality 90 before committing
(about 80 KB each, visually identical). Prompts: `docs/exercise-image-prompts-sample.md`;
style guide: `docs/exercise-image-design.md`.

Approved so far (test set, 2026-10-16): push-up, barbell-back-squat, kettlebell-swing, pull-up,
dumbbell-fly, band-pull-apart, plank, cable-triceps-pushdown, dumbbell-bulgarian-split-squat, leg-press.
